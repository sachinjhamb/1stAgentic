# Product Overview

A clean, responsive To-Do application for managing tasks with scheduling and reminders.

## Core Features

- Task management (add, complete, delete)
- Subtasks with priority levels and notes
- Due date/time scheduling with smart defaults
- Browser notifications (5 minutes before due time)
- Progress tracking with weighted subtasks
- localStorage persistence
- Keyboard shortcuts (/ to focus input, Ctrl+Shift+Delete to clear all)
- Status indicators (overdue, due soon, completed)

## User Experience

- Minimal, gradient-based UI design
- Mobile-responsive layout
- No external dependencies or build process
- Runs entirely in the browser with no backend
